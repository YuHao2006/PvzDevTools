# DAT64 v4 初始记录契约

`initial-records-v4.json.gz` 是独立存档生成器的版本化默认状态数据。它从 v4 初始化检查点的序列化记录整理并冻结，按模式／冒险关卡和六种场景组织。开发期对照游戏初始化结果验证，但发布工具的构建和运行不依赖游戏仓库、对象文件、可执行程序或资源包。

数据包含：棋盘与各模式的默认记录、首次／通关后冒险初值、植物及其动画／附件／常驻粒子的状态记录、墓碑／梯子／耙子记录、时间字段描述。它不包含动画定义中的关键帧变换、纹理、音频、PAK 或可执行代码。记录中的外部图像／定义 ID 属于已冻结的存档契约，实际游戏读档后自行解析。

压缩内容是 JSON：`buffers` 保存去重的 Base64 字节块，`data` 中 `$bytes` 引用字节块、`$ns` 保存十进制整数纳秒。`data.version=1`；底层存档格式仍为 v4。解压和解析在专用工具 Worker 内执行，字节块在恢复时复制，避免共享默认记录被修改。

新实例必须重分配每个池的 ID，递归处理动画轨道附件、附件效果、粒子系统的发射器及粒子列表；不能直接拼接带原 ID 的记录。位置移动同时调整浮点状态、整数兼容投影、绘制顺序和世界坐标的睡眠动画／粒子中心。输出经过 C++ 格式核心完整校验，输入及默认数据均不原地修改。

格式破坏性更新时需单独升级此契约并重新做真实读档回归。本轮不引入 v5。此数据不是用户存档，也不包含用户账号或进行中的关卡进度。
